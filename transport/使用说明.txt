交通工具中文复习与三天作业

打开网页
解压后进入 transport 文件夹，用浏览器打开 index.html。
请保留 index.html、assets 文件夹和 audio 文件夹的相对位置。

上传 GitHub Pages
将 transport 文件夹中的文件整体上传到课程目录。不要只上传 index.html。
图片位于 assets/images/，音频位于 audio/。

TTS
已经包含37条预生成MP3。点击按钮直接播放，无需设备安装中文朗读声音。
固定文本使用 data-tts-text；动态文本列在 script#tts-texts 的 JSON 中。
播放映射为 audio/tts-manifest.js 中的 window.TTS_AUDIO。
音频生成参数：zh-CN-XiaoyiNeural，语速-25%，音高+8Hz。
修改朗读文字后，可使用现有 Build TTS Audio 工作流重新生成。
generate_audio.py 会扫描同层所有HTML，合并去重并更新 tts-texts.json、audio/ 和 tts-tests.json。
手动生成：安装 edge-tts 后运行 python generate_audio.py。

使用提示
录音是可选功能，不上传、不自动评分。某些浏览器仅允许在HTTPS网页中录音。
学习记录保存在当前设备的浏览器里，不会跨设备同步。
